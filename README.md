# GameHub v2

A lightweight free-game portal with browser-playable mini-games.

Included games:
- Neon Runner
- Snake
- Pong
- Click Rush
- Memory Flip
- Brick Breaker
- Sky Dodge
- Reaction Test

Performance focus:
- No external image assets
- No Google Fonts dependency
- No heavy backdrop filters
- No continuously animated UI effects
- Games use lightweight canvas loops and stop when the modal closes
- Game data is local and searchable

Open `index.html` directly or run:
`python -m http.server 8000`

All games in this starter are original mini-games written for this project.
